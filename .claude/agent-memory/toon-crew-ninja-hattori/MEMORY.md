# Ninja Hattori: lessons

- Path guards that lstat/realpath a path and then open it need O_NONBLOCK on the open and an nlink === 1 check: a FIFO swapped in after the check blocks open() before any fstat re-check runs, and realpath cannot see a hard link. (seen 1) [crew]
- Streaming line readers: keep the unfinished line as a list of chunks and concat once at "\n". Buffer.concat on every read is quadratic: a 200 MB line pushed peak RSS to about 2.7 GB despite a 64 MB line cap. Measure peak memory in a child process with process.resourceUsage().maxRSS, never in the test runner. (seen 1) [crew]
- Records keyed by names a user or folder controls (project basenames) must not use `obj[k] = v` on `{}`: "__proto__" swaps the prototype and the key disappears from the JSON. Use Map, Object.fromEntries or defineProperty. Object.create(null) breaks existing deepStrictEqual checks against `{}`. (seen 1) [crew]
- Cumulative snapshots where the newest one wins: a capped or partial read must not replace a larger earlier total, and the partial flag must reach every rollup level (room, agent, task). (seen 1) [crew]
- To prove fixes without touching the repo: `git archive <sha> <paths> | tar -x` into the work folder, patch it with a node script that throws if a target string is missing, point the proofs at the copy with a path rewrite, and run the repo's own suite on the patched copy. (seen 1) [crew]
- Text guards must treat a glob in a write target as "anything below its literal prefix". Testing the glob against a fixed list of protected file names misses deeper files (git hooks, plugin modules, memory files), and bash and zsh both expand globs in redirects and cp targets. Expand with fs.globSync and check each match, or refuse a glob whose literal prefix sits inside or above a protected root. (seen 1) [crew]
- Protect every module a fail-closed hook imports, not just its entry file. A replaced helper that keeps the named exports and calls process.exit(0) makes the hook exit 0 before its body runs, so every call is allowed; a broken import only exits 1. (seen 1) [crew]
- The toon-crew guard blocks shell writes it cannot place under $TMPDIR (relative redirects, `$VAR` paths, `sed -i ''`, inline code that mentions deleting files) and, for read-only roles, `git commit` and `.git/hooks` paths even inside temp. In the work folder, use literal absolute paths, or write helper scripts with Write and run them with node. Guard glob checks are text-only, so probes don't need the files to exist. (seen 2) [project]
- A fake HOME under $TMPDIR gives false allows for read-only roles, because their write roots include temp. Check read-only roles with a decision-only evaluate() call on the real HOME and paths; it writes nothing. (seen 1) [project]
- Every board hook payload field needs a type and pattern check before appendEvent (hook.ts uses agentIdOf/agentTypeOf); a non-string field used to crash buildState. server.ts now catches build errors and answers a fixed 500 line. (seen 1) [project]
