# Nobita memory

- For read-only roles the toon-crew guard blocks `sed -i`, `perl -e`, `node -e` that writes, and "write a script and run it" in one command. Write the script with the Write tool, then run it with `node <file>` in a separate call. Shell writes must use literal absolute scratchpad paths: `$VAR` paths, `cd … &&` chains and `mkdir` mixed with other commands get blocked. (seen 4) [crew]
- Seed board demo data into a new folder of your own (for example `scratchpad/nobita-demo`). `scratchpad/demo` may belong to another agent, and `board-demo.mjs` refuses a non-empty folder that lacks its marker. (seen 4) [project]
- The board's CSP is `default-src 'none'` with no `font-src`, so "Press Start 2P" never loads and the pixel headings render in system mono. Any web font must be a `data:` URI plus a CSP change, reviewed by security. (seen 1) [project]
- Agent types are namespaced (`toon-crew:kevin`), so any parser that splits on the first colon garbles hand-back text. Check desks, bubbles and log rows for "x finished:" or "toon-crew:" leaking into the UI. (seen 1) [project]
- Mascot names carry pets ("Ninja Hattori + Shishimaru", "Shinchan + Shiro"). Check every text context (cost bars, task rows, log, tables) for the pet suffix and for labels cut by fixed-width columns. (seen 1) [project]
- To film walkers: load the room with `localStorage.crewMotion = "on"`, then append fresh `assign`, `agent-start` and `agent-stop` events (ts = now) to the demo `events.jsonl` right before filming. Walks only play for events under 2 minutes old (task walks under 20 s). Faster: `room.js` is a classic script, so call `rVisit({kind:"visit", role, to, say:"", proj})` from CDP `Runtime.evaluate`; set `rLastCheck` far ahead to stop check-ins interfering. (seen 3) [project]
- Test one-shot scenes on the live path too: open the page, let the replay settle, then append the events and log a 50 ms DOM timeline with a screenshot per change. The on-load replay hides bugs the live flow has (the clone scene never fired live because the assign walk kept Doraemon away). (seen 1) [crew]
- A reveal scene must hold back every encoding of the new state (badge, count, status copy, room sign), not only the sprite. Check the first frame before the effect for spoilers. (seen 1) [crew]
- An async scene that holds a desk element across `await`s breaks when the desk re-renders (`rWake` / `rRefreshDesk` replace the node). Check for stale element references in every scene function. (seen 1) [project]
- To test animation direction without touching product code, inject prototype CSS and JS into the running page over CDP (classic-script function globals can be reassigned), then crop screenshots around the moving element and lay them out as contact sheets to judge at real size. (seen 1) [crew]
- Animation review checks: an arrival pose must play after the sprite turns toward its target (from behind it is invisible); a sprite that vanishes needs a cover effect; trail bits laid on vertical legs stack into a pole; cap live effect nodes per layer; a straight beam or line between two seats at face height crosses every face in between, so route it above heads and land the flash where the new thing appears. (seen 2) [crew]
- Film-look SVG avatars (Mike, Sulley, Joe, 22) keep their face when the walker faces "up", unlike the CSS-part avatars. Any "walk into something" moment needs a fade. (seen 1) [project]
- Simulate offline, loading, "not tracked" and rare states (for example a stale member) by intercepting `/api/state` (CDP `Fetch.enable` at the Response stage, then rewrite the JSON). No server changes and no second data folder needed. (seen 2) [crew]
- Automated contrast scans misread layered or gradient backgrounds (pixel plates, walls). Check those pairs by hand; don't report them as failures. Also check dimmed states: `opacity` on a container drops muted text below AA. Without PIL, a small zlib PNG decoder in Python reads pixel pairs from existing frames. (seen 4) [crew]
- Count every number in one header strip and across a room. A chip count, a "n working" line, a meter, a room sign, a badge and status copy can all show the same figure, and they can disagree when they come from different sources. (seen 2) [crew]
