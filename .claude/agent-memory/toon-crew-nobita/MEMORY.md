# Nobita memory

- For read-only roles the toon-crew guard blocks `sed -i`, `perl -e`, `node -e` that writes, `python3 -c` that writes, and "write a script and run it" in one command. Write the script with the Write tool, then run it with `node <file>` or `python3 -I <file>` in a separate call. Shell writes must use literal absolute scratchpad paths: `$VAR` paths, `cd … &&` chains and `mkdir` mixed with other commands get blocked. A program named by a variable (`"$C" --headless`) is blocked too, so spell out the Chrome path. The guard also blocks a grep pattern that contains `function name(`, because it reads as a shell function definition. (seen 6) [crew]
- The guard that runs is the installed plugin cache version, not the repo's. If the cache still lists nobita as read-only, a brief that says "you may edit room.css" can't be done: shell and Write to product files are blocked. Check `READ_ONLY_ROLES` in the cached `guard.mjs` first; if blocked, deliver the CSS as a scratch file, test it linked after the real room.css, and say so in the hand-back. Never try to get around the guard. (seen 1) [project]
- When a builder writes markup in parallel, read their worktree (`.claude/worktrees/agent-*/plugin/board/room.js`) before styling, and place every child by `grid-area` with class or tag selectors, so the DOM order (for example a badge appended last) doesn't matter. (seen 1) [crew]
- In a bar list, give the number column a fixed width (for example `6.5em`), not `auto`. With `auto`, each row's text width ("4.6% of plan" vs "19% of plan") changes the bar's length, and equal values draw unequal bars. (seen 1) [crew]
- Seed board demo data into a new folder of your own (for example `scratchpad/nobita-demo`). `scratchpad/demo` may belong to another agent, and `board-demo.mjs` refuses a non-empty folder that lacks its marker. (seen 5) [project]
- The board's CSP is `default-src 'none'` with no `font-src`, so "Press Start 2P" never loads and the pixel headings render in system mono. Any web font must be a `data:` URI plus a CSP change, reviewed by security. (seen 1) [project]
- Agent types are namespaced (`toon-crew:kevin`), so any parser that splits on the first colon garbles hand-back text. Check desks, bubbles and log rows for "x finished:" or "toon-crew:" leaking into the UI. (seen 1) [project]
- Mascot names carry pets ("Ninja Hattori + Shishimaru", "Shinchan + Shiro"). Check every text context (cost bars, task rows, log, tables) for the pet suffix and for labels cut by fixed-width columns. (seen 1) [project]
- To film walkers: load the room with `localStorage.crewMotion = "on"`, then append fresh `assign`, `agent-start` and `agent-stop` events (ts = now) to the demo `events.jsonl` right before filming. Walks only play for events under 2 minutes old (task walks under 20 s). Faster: `room.js` is a classic script, so call `rVisit({kind:"visit", role, to, say:"", proj})` from CDP `Runtime.evaluate`; set `rLastCheck` far ahead to stop check-ins interfering. Desks are keyed by `data-id` (not `data-role`); `rDeskEl(id, proj)` finds one. (seen 4) [project]
- To judge a path, log the walker's `_p` every frame and reduce it to turning points (R/L/U/D), and print `rRoute(...)` next to it. A path that dips down then climbs back up shows at once; screenshots alone hide it. (seen 1) [crew]
- Room routes in `rRoute` go seat, stand, down to the lane under the name plate, across to the room centre, then up to the top-door corridor. A cross-room trip therefore dips down and climbs the whole room twice, walks over name plates anyway, and the corridor line (`cy`) puts the walker above the hall frame. (seen 1) [project]
- Test one-shot scenes on the live path too: open the page, let the replay settle, then append the events and log a 50 ms DOM timeline with a screenshot per change. The on-load replay hides bugs the live flow has (the clone scene never fired live because the assign walk kept Doraemon away). (seen 1) [crew]
- A reveal scene must hold back every encoding of the new state (badge, count, status copy, room sign), not only the sprite. Check the first frame before the effect for spoilers. (seen 1) [crew]
- An async scene that holds a desk element across `await`s breaks when the desk re-renders (`rWake` / `rRefreshDesk` replace the node). Check for stale element references in every scene function. (seen 1) [project]
- To test animation direction without touching product code, inject prototype CSS and JS into the running page over CDP (classic-script function globals can be reassigned), then crop screenshots around the moving element and lay them out as contact sheets to judge at real size. Headless Chrome `--screenshot=<png> file://sheet.html` renders a contact sheet without PIL. (seen 2) [crew]

- Automated contrast scans misread layered or gradient backgrounds (pixel plates, walls). Check those pairs by hand; don't report them as failures. Also check dimmed states: `opacity` on a container drops muted text below AA. Without PIL, a small zlib PNG decoder in Python reads pixel pairs from existing frames. (seen 4) [crew]
